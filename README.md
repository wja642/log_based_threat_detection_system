# Log-Based Threat Detection System

A Python-based cybersecurity application that monitors system logs and detects suspicious activities using predefined security rules.

## Features

- Log file monitoring
- Real-time log monitoring
- Threat detection
- 50+ detection rules
- Custom rule management
- IP/blocklist management
- Gmail email alerts
- Security reports
- Password-protected application
- SQLite database
- PyInstaller executable support

## Technologies

- Python
- Tkinter
- SQLite
- SMTP
- Regular Expressions
- Cybersecurity / SIEM concepts

## Security Tools & Concepts

- Log Analysis
- Threat Detection
- Network Security
- Incident Detection
- SIEM Concepts
- IP Blocking

## Project Objective

The system analyzes log data and identifies potentially suspicious activities based on predefined security rules, helping users detect security incidents quickly.
